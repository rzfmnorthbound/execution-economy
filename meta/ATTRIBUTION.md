## How to Cite

When referencing or adapting the ideas presented in this repository, please cite:

Ruiz, Francisco.  
*The Execution Economy: A New Enterprise Model Where Value Follows Execution.*  
Execution Economy Initiative, 2026.

---

## Attribution Guidelines

If you reference the framework in articles, research, presentations, or derivative works, please include:

- the author’s name
- the framework name (Execution Economy)
- a link to the repository

Example:

“This work builds upon the Execution Economy framework introduced by Francisco Ruiz (2026).”

---

## Purpose of Attribution

Attribution ensures that the intellectual origin of the framework remains clear while allowing the ideas to circulate, evolve, and be implemented across industries.
